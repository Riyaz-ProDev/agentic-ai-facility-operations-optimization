# 🏢 Agentic AI for Smart Facility Operations & Optimization

An AI-powered facility management platform that uses intelligent agents to monitor **energy, equipment health, occupancy, security, and operational costs**.

## 🚀 Live Demo

👉 [Launch FacilityOps](https://agentic-ai-facility-operations-eqrm.onrender.com)

## 💻 Run Locally

### Backend

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
